## 1. `server/server.js` — register the service (required)
After the `ctx.services.safety = …` line:
```js
  ctx.services.integrity = require("./services/integrity")(ctx);  // Phase 32: fake-account signals, investigations, fake-follower cleanup
```
It registers its routes and two leased jobs on `ctx.scheduler` (`integrityScan`, `fakeFollowerCleanup`); `close()` already stops the scheduler.
The tests and e2e attach the service themselves only when `ctx.services.integrity` is missing, so they keep passing after this line is added.

## 4. Soft-limit hooks (recommended — without them a limit only shows in the UI and the trust score)
One line at the top of each action, right after the existing `rl.hit(...)` check:
```js
// server/services/users.js → follow(user, to)
await ctx.services.integrity?.guard(user.id, "follow");
// server/services/content.js → createPost(user, b)
await ctx.services.integrity?.guard(user.id, "post");
// server/services/content.js → comment(user, b)
await ctx.services.integrity?.guard(user.id, "comment");
// server/services/content.js → react(user, target, type)
await ctx.services.integrity?.guard(user.id, "react");
// server/services/chat.js → send(user, cid, b)   (and messaging send if still used)
await ctx.services.integrity?.guard(user.id, "message");
```
`guard` is a no-op for accounts without a limit (one indexed lookup) and throws `HttpError(429, <Arabic text>, "integrity_limited")` otherwise.

## 5. Public follower counts exclude soft-hidden fake followers (recommended)
Replace the follower COUNT in these three places:
```js
// server/services/identity.js fullProfile() line ~29 and card() line ~55, server/services/users.js profile() line ~119
const followers = ctx.services.integrity ? await ctx.services.integrity.visibleFollowerCount(u.id) : (await db.get("SELECT COUNT(*) n FROM follows WHERE dst=$1", [u.id])).n;
```
and in `server/services/reputation.js` computeReputation (reach):
```js
const reach = Math.sqrt(ctx.services.integrity ? await ctx.services.integrity.visibleFollowerCount(uid) : await count("SELECT COUNT(*) n FROM follows WHERE dst=$1", [uid])) * 3;
```
(follower lists are unchanged; the follows rows are never touched.)
