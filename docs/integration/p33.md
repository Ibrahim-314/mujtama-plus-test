## A. Edits the integrator must apply to shared files (not touched on this branch)

### 1. `server/server.js` — register the service (after `safety`, which it calls)
```js
  ctx.services.safety = require("./services/safety")(ctx);
  ctx.services.protection = require("./services/protection")(ctx);  // Phase 33: linked blocks, timed mutes, protection mode, reply controls, help center, policies, 3-step reports
```
Any position works for the hooks below (they resolve `ctx.services.protection` lazily), but it must be
registered before the first request. Nothing else in server.js changes (no new jobs, no new env needed).


and `window.ExtraRoutes` (new routes `#/help[/slug]`, `#/protection`, `#/policies[/slug]`). Chunk layers that
load later wrap on top of it; that order was exercised in the e2e test.
