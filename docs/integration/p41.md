## Deviations / additions vs the contract
- Extra error codes: 400 `consent_required`, `plan_invalid`, `string_invalid`; 409 `invalid_state` (cancel without a live subscription).
- `GET /api/ai/me.subscription.state` is computed (`active` only while `period_end` is in the future).
- Batch requests ignore duplicates; E2EE messages in a batch need `text` + `consent` per item.
