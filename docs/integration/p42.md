## Gate, caps, provider
- Every call: `ai.requireFeature(uid, "assistant")` → 402 `subscription_required` + upsell. The plan `ai_plus` gets `assistant` once
  (flag `assistant_meta.plan_seeded`; an admin removing it is respected; `AI_ASSISTANT_IN_PLAN=0` skips the seed).
- Provider: OpenAI-compatible, env key only — `ASSISTANT_API_KEY` (or shared `OPENAI_API_KEY`), `ASSISTANT_BASE_URL`/`OPENAI_BASE_URL`,
  `ASSISTANT_MODEL` (gpt-4o-mini), `ASSISTANT_EMBED_MODEL` (text-embedding-3-small). No key → 503 `not_configured` «المساعد الذكي غير مفعّل بعد».
- Caps via `ai.checkCaps`/`ai.meter` feature `assistant`: `plan.limits.assistant {chars, costUsd}` or `AI_ASSISTANT_MONTHLY_CHARS` (100000) /
  `AI_ASSISTANT_MONTHLY_USD` (0.5); global `AI_PROVIDER_MONTHLY_USD`. Provider cost rates only from env (`ASSISTANT_USD_PER_MTOK_IN|OUT|EMBED`,
  default 0 → only char caps bite). Index cost → `ai_period_stats` feature `assistant_index` (no user ids).
  Note: admin `PUT /api/admin/ai/plans/:slug {limits}` still validates only `translate`; assistant limits are set in `ai_plans.limits` JSON.

## Privacy
Only the user's own draft, the query, and PUBLIC content (visibility public, published, not paid, no community or a `public` community)
reach the provider. Messages/E2EE are never read (`kind:"message"` → 400). Non-public target → 409 `private_content`. Inputs/outputs not stored or logged.

## Vector store
`assistant_vectors` (doc `post:<id>` / `comment:<id>`, base64 Float32, model, dims; no user ids). PostgreSQL with pgvector ALREADY installed →
runtime `ADD COLUMN IF NOT EXISTS embedding vector` + `<=>` search; otherwise JS cosine (newest `ASSISTANT_VECTOR_SCAN_MAX`=5000).
`ASSISTANT_PGVECTOR=auto|create|off` (create only if available). Job `assistant.index` every `ASSISTANT_INDEX_INTERVAL_MS` (10 min,
`ASSISTANT_JOBS=0` off), batch `ASSISTANT_INDEX_BATCH`=32. POST_UPDATED/POST_DELETED forget vectors; visibility re-checked at query time.

## API (session, `X-Requested-With: mujtama`)
- `GET /api/assistant/config` → `{available, provider|null, note?, modes, label, store:"js"|"pgvector", transparency}`
- `GET /api/assistant/me` → `{entitled, available, note?, usage:{period, requests, chars, limitChars, pct}}`
- `POST /api/assistant/write {text ≤4000, mode: rephrase|improve|shorter|polite}` → `{mode, text, ai, label, provider}`
- `POST /api/assistant/replies {kind: post|comment, id, draft?}` → `{suggestions:[≤3], ai, label}`
- `POST /api/assistant/ask {q}` → `{points:[{text, cites:["s1"]}], sources:[{id, kind, refId, postId, snippet, href, cited}], grounded: model|extractive|none, note?}`
  (points verified by `lib/llm.verify`; nothing supported → verbatim extractive sentences)
- `POST /api/assistant/search {q, limit?}` → `{items:[{kind, id, postId, score, snippet, href}], store}`
- Admin: `GET /api/admin/assistant/status`, `POST /api/admin/assistant/reindex`.
Errors: 401, 402, 400 `bad_request`, 404, 409 `private_content`, 429 `usage_limit`|`rate_limited`, 503 `not_configured`|`budget_exhausted`|`provider_error`.

## UI
«✨ المساعد» after `textarea#txt` (post composer) and `input#cin` (comment box). Non-subscriber → `MPAI.upsell()` + assistant note.
Subscriber sheet `#mp-as-sheet`: 4 writing modes, «اقترح ردوداً مهذبة» (post page), ask/search, usage %, «ما الذي يراه المساعد؟» (`#mp-as-why-s`).
Suggestions only fill the field after «استخدام»; nothing is posted automatically. `window.MPAssistant {open, why, refresh, attach}`.
