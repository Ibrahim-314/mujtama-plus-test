# Phase 43 — full accessibility (integration notes)

Branch `p43` on 978ed28 (v2.14.0). Target 2.16.0; versions not bumped. Everything is free for all users.

## Server
- Migration `server/migrations/026_a11y.js` (additive): `a11y_prefs` (user_id, key `a11y.*`, JSON value), `media_alt`,
  `video_captions`, `a11y_audits`.
- Service `server/services/a11y.js`, wired in `server/server.js` (one line, before minors) with `config.a11yOpts`
  (`{ vision, captioner, jobs, env, now }` for tests).
- Routes: `GET /api/a11y/config` · `GET|PUT|DELETE /api/me/a11y` (whitelist: fontScale, contrast, dyslexia, spacing, motion,
  underlineLinks, focusRing, captions, altReminder; default values are not stored) · `GET /api/a11y/alt?ids=` ·
  `GET|PUT /api/a11y/alt/:mid` · `POST /api/a11y/alt/:mid/auto` · `GET /api/a11y/captions/:mid` · `GET …/:mid/:lang.vtt` ·
  `PUT|DELETE …/:mid/:lang` (`{ vtt, label }`, SRT accepted) · `GET …/:mid/:lang/source` · `POST …/:mid/auto` ·
  `GET /api/admin/a11y/audits` · `POST /api/admin/a11y/audits/run` · `POST /api/admin/a11y/audits` (CI report body).
- Alt text order: user → auto → heuristic (from the post text, computed on read, never stored). Nothing is revealed for media
  that is not in a published public post unless the caller owns it.
- Vision (optional): `A11Y_VISION_KEY` or `OPENAI_API_KEY`, `A11Y_VISION_URL`/`OPENAI_BASE_URL`, `A11Y_VISION_MODEL`
  (default gpt-4o-mini). Only public, non-paid images ≤ 4 MB; never overwrites user text. No key → heuristic only.
- Auto captions (optional): `A11Y_ASR_KEY` / `OPENAI_API_KEY` / `WHISPER_API_KEY` or `WHISPER_URL`. No key → 503
  `not_configured`, manual WebVTT only. Captions are mirrored into `media.variants.captions` + the post so the existing player
  renders `<track>` (URL `/api/a11y/captions/:mid/:lang.vtt`).
- Scheduled job `a11y.audit` (leased, default daily `A11Y_AUDIT_INTERVAL_MS`, off with `A11Y_JOBS=0`): COUNT queries only
  (7-day alt/caption coverage, last CI result); with a vision key it also describes ≤ `A11Y_VISION_MAX_PER_RUN` (10) recent
  public images. Runs older than 180 days are deleted.

## Client
- Lazy chunk `a11y-ui.js` (`data-chunk="a11y"`, 8.7 KB br), idle-loaded for everyone (chunks.js) and for
  `#/settings/display`, `#/a11y/captions/:mid`, `#/accessibility`, `#/admin/a11y`.
- Core: +62 B br (89.4 KB → 89.5 KB). `platform.js` one line injects the saved CSS (`localStorage.mp_a11yCss`) before first
  paint; CSS bundle unchanged (all a11y CSS is generated in the chunk).
- `index.html`: `main#view tabindex=-1`, nav `aria-label`, icon-button / FAB `aria-label`, toast `role=status aria-live`.
  `community-ui.js`: label on the directory sort `<select>` (axe select-name).
- Chunk adds: skip link, live region + focus to the new heading after navigation, `aria-current` on nav, modal contract for
  `#sheet .panel` and body-level `[role=dialog]` (composer): focus in, Tab trap, Escape, focus restored; names for icon/emoji
  buttons and unlabeled fields, `role=article` posts with j/k, `role=img` + alt on media backgrounds, alt on gallery `<img>`,
  ALT editor on own images, caption editor link on own videos, captions-by-default.
- Phase 44 note: display prefs live only under `a11y.*` in `a11y_prefs`; high contrast overrides the theme custom properties
  (`--bg`, `--text`, …) including `[data-theme=dark]`, so it wins over any theme. `<html data-a11y="…">` flags are exposed.
