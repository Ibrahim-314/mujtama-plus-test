# مجتمع بلس — المسار السابع: الثقة والأمان

## المرحلة 31: الإشراف الآلي

> فريق المرحلة 31. الخادم: `server/services/automod.js` + `server/lib/ar-classify.js` + `server/lib/linkscan.js` + `server/lib/imgscan.js`، الترحيل `014_automod`. الواجهة: `automod-ui.js`.
> المبدأ: **لا حذف آلي أبداً**. الآلة تؤخّر أو تحجز أو تصعّد، والإنسان وحده يحذف، وكل حذف قرار عادي قابل للاستئناف عبر `/api/appeals`.

### كيف يعمل (خط المعالجة)

```text
POST /api/posts | /api/comments | chat message
   │  (اختياري: gate() داخل content.js قبل الإدراج → صفر نافذة ظهور)
   ▼
bus: POST_CREATED / POST_UPDATED / COMMENT_CREATED / MESSAGE_SENT
   ▼  المرور الأول (متزامن تقريباً، < 1ms للنص): تصنيف النص + فحص الروابط + طبقة الثقة للحساب
   ├─ allow     → لا شيء
   ├─ delay     → status='held' + release_at (افتراضياً 10 دقائق) — ينشر تلقائياً إن لم تصل بلاغات
   ├─ hold      → status='held' بانتظار مراجعة بشرية
   └─ escalate  → status='held' + بلاغ نظامي في reports (يظهر في لوحة الإدارة وطابور المجتمع)
   ▼  المرور الثاني: مهمة دائمة «automod.deep» على ctx.queue (تنجو من إعادة التشغيل، تعيد المحاولة)
      صور المنشور (بصمات محظورة، بيانات وصفية، نسبة لون البشرة، مزوّد خارجي اختياري) + نموذج لغوي اختياري
   ▼  مُجدول كل دقيقة: releaseDue() — ينشر المؤجَّل، أو يصعّده إن وصلته بلاغات خلال التأخير
```

الرسائل الخاصة **لا تُخفى أبداً** (خصوصية): إن احتوت رابطاً ضاراً أو احتيالاً يصل للمستلم حدث `automod_flag` وتحذير لطيف، وأي نقرة على الرابط المعلَّم تفتح شاشة تنبيه قبل مغادرة التطبيق.

### 1. مصنّف النصوص العربية (`lib/ar-classify.js`)

- الفئات: `abuse` (إساءة/شتائم/تحرش)، `threat` (تهديد)، `hate` (كراهية: ألفاظ عنصرية/طائفية + نمط «جماعة + تجريد من الإنسانية/دعوة للعنف»)، `fraud` (احتيال: عبارة المرور/الكلمات الـ24، «ضاعف أموالك»، أرباح مضمونة، تهديد بإيقاف الحساب، وعد مالي + طلب تواصل، رقم هاتف + مال).
- تطبيع ضد التحايل: التشكيل والتطويل، أشكال الألف والهمزة والتاء المربوطة والألف المقصورة، الحروف الفارسية (ک ی ڤ پ چ…)، المحارف الخفية (zero-width/bidi)، التمطيط (حماااار)، الحروف المفصولة (غ.ب.ي / غ ب ي / ح_م_ا_ر)، العربيزي (7mar، 8abi، kalb) بقائمة صريحة + هيكل ساكن مُحوَّل، والـ leet الإنجليزي (1d10t، $tupid).
- السياق: المخاطَبة (يا/انت/you) ترفع الدرجة، النفي (مو/مش/ليس/not) يخففها للنصف، وأسماء الحيوانات لا تُحسب كاملة إلا إن وُجّهت لشخص («عندي كلب» ≠ «يا كلب»).
- يُستخدم `lib/toxicity.js` (المرحلة 17) كحدّ أدنى، فلا يختلف المصنّفان نزولاً.
- **تبسيط صريح**: معجم + قواعد، لا نموذج تعلّم آلي. دقته جيدة للحالات الصريحة وضعيفة للسخرية والسياق البعيد؛ لذلك لا يحذف شيئاً، وللحالات الحدّية نموذج لغوي اختياري.

### 2. فحص الصور (`lib/imgscan.js`)

بصمة SHA-256 (مطابقة تامة) + بصمة إدراكية 8×8 (نفس `lib/images.js`؛ تشابه ≤ 5 بتات) من قائمة الإدارة، كلمات دالة في البيانات الوصفية (EXIF/XMP/PNG)، ونسبة البكسلات بلون البشرة (قواعد RGB + YCbCr) وأكبر منطقة متصلة بعد فك الصورة إلى 64×64 عبر ffmpeg. **الإرشاد اللوني وحده لا يحجب شيئاً**: يضع `posts.sensitive=1` فتظهر الصورة مموّهة خلف «اضغط للعرض» (السلوك الحالي في الواجهة). الحجب فقط عند تطابق بصمة محظورة أو مزوّد خارجي واثق (≥ 0.85).

### 3. الروابط الضارة (`lib/linkscan.js`)

يستخرج الروابط من النص (مع أو بدون https، وروابط Markdown) ومن مستندات النص المنسّق (`[text, marks, href]`). يكشف: قائمة النطاقات الضارة (بذرة مدمجة + جدول `automod_domains` للإدارة، مع قائمة سماح)، المختصِرات (bit.ly…)، عناوين IP، خدعة `@` (https://minepi.com@evil.tk)، punycode وخلط الأبجديات (Cyrillic «і» داخل minepi)، النطاقات الشبيهة بالعلامات المعروفة (minep1.com، paypa1…) بالمسافة التحريرية على «الهيكل البصري»، الامتدادات الخطرة، كثرة النطاقات الفرعية، كلمات الاستدراج، `javascript:`/`data:`، و**نص العرض المضلِّل** (رابط يعرض minepi.com ويذهب لغيره). محلي بالكامل، دون أي اتصال خارجي.

### 4. التأخير الذكي بدل الحذف

`posts.status` / `comments.status` = `'held'` (حالة جديدة لا تحتاج ترحيلاً — العمود نصي). سياسة الرؤية الحالية تُظهر المحتوى لصاحبه فقط، والخلاصات والتعليقات تعرض `published` فقط. يُحفظ `prev_status` (published/processing/scheduled) ويُستعاد عند الإفراج؛ منشورات الفيديو المحجوزة تُكمل المعالجة بعد الإفراج (`finishMediaPost`). **تعديل صاحب المنشور** إلى نص سليم يفرج عنه فوراً (ما لم يكن مصعَّداً أو بسبب صورة).

| الحالة | المعنى | تنتهي إلى |
|---|---|---|
| `delayed` | تأخير قصير (`AUTOMOD_DELAY_MIN`) | `released` تلقائياً، أو `escalated` إن وصلت بلاغات |
| `held` | بانتظار مراجعة | `released` / `removed` / `escalated` |
| `escalated` | خطير أو مُبلَّغ عنه + بلاغ نظامي | قرار إداري |
| `flagged` | رسالة خاصة بتحذير للمستلم | — |
| `cleared` | سجل فحص صور لم يُحجب | — |

العتبات (قبل إزاحة الطبقة): delay ≥ 0.5، hold ≥ 0.7، escalate ≥ 0.85، أو «خطير» دائماً: تهديد ≥ 0.8، كراهية ≥ 0.75، احتيال ≥ 0.8، نطاق محظور، رابط ينفّذ شيفرة.

### 6. حدود معدل تتكيف مع عمر الحساب

يلتف الخادم حول `ctx.rl.hit` المشترك (بلا تعديل `core.js`) ويضرب حدود الإجراءات (نشر، تعليق، تفاعل، رفع، متابعة، رسالة، دعوة، بلاغ، مجتمع) بمعامل طبقة الثقة:

| الطبقة | الشرط | المعامل | إزاحة العتبات |
|---|---|---|---|
| `new` | عمر < يوم | ×0.75 نشر/تعليق، ×0.5 متابعة/رسائل/رفع، ×⅓ دعوات | −0.10 |
| `young` | < 7 أيام | ×0.75 متابعة/رسائل/رفع، ×0.5 دعوات | −0.05 |
| `standard` | — | ×1 | 0 |
| `trusted` | موثَّق، أو ≥ 30 يوماً + سمعة ≥ 100 دون مخالفات، أو مدير | ×2 | +0.10 |
| `restricted` | ≥ 2 قرارات خلال 30 يوماً أو ≥ 3 حجوزات خلال 7 أيام | ×0.5 | −0.15 |

الطبقة تُحسب غير متزامن وتُخزَّن 10 دقائق (أول طلب لحساب غير معروف يستخدم الحد العادي). `GET /api/automod/limits` يعرض للمستخدم طبقته وحدوده بشفافية. التعطيل: `AUTOMOD_ADAPTIVE_RL=0`.

### 7–8. الواجهة (`automod-ui.js`)

- **«هل أنت متأكد؟»**: يلتف حول `Remote.api` فيفحص نص التعليق/الرد/المنشور عبر `POST /api/automod/check` (يُصنَّف في الذاكرة ولا يُخزَّن). عند العدائية: حوار `alertdialog` يبدأ التركيز فيه على «تعديل الرد»، Escape = تعديل، و«النشر على أي حال» متاح دائماً. لا يمنع النشر إن تأخر الفحص (> 1.5 ث) أو فشل. نتيجة الاختيار فقط (دون نص) تُسجَّل لقياس الأثر.
- **رسائل لطيفة**: شريط «بانتظار مراجعة سريعة» على بطاقة المنشور المحجوز لصاحبه + زر «لماذا؟»، إشعار فوري (حدث `automod`)، و`MPAutomod.openHeld()` لقائمة «قيد المراجعة» مع ما يمكن فعله.

### واجهة برمجية

| المسار | الوصف |
|---|---|
| `POST /api/automod/check` `{text}` | `{ nudge, level: none|gentle|strong|risky, message, explanations[], categories, terms[] }` |
| `POST /api/automod/nudge` `{level, outcome: edited|posted|cancelled}` | قياس أثر التنبيه |
| `GET /api/automod/mine` | عناصري قيد المراجعة مع الشرح |
| `GET /api/automod/explain/:target` | شرح عنصر (لصاحبه أو للإدارة) |
| `GET /api/automod/flags/:conv` | تحذيرات رسائل المحادثة (للأعضاء، دون رسائلي) |
| `GET /api/automod/limits` | طبقتي وحدودي |
| `GET /api/admin/automod?state=open|delayed|held|escalated|released|removed|flagged|cleared` | طابور الإدارة |
| `POST /api/admin/automod/:id` `{action: release|remove|escalate, reason}` | قرار (الحذف ينشئ decision قابلاً للاستئناف) |
| `GET /api/admin/automod/lists` · `POST /api/admin/automod/domains` `{domain, verdict: bad|ok}` · `DELETE /api/admin/automod/domains/:d` | قوائم النطاقات |
| `POST /api/admin/automod/hashes` `{media | hash, label}` | حظر صورة ونسخها المشابهة |
| `GET /api/admin/automod/stats` | أعداد الحالات (7 أيام) ونسبة من راجع نصه بعد التنبيه |

أحداث: `CONTENT_HELD {kind,target,author,state,reasons}` على الـ bus؛ للعميل عبر SSE (`ctx.realtime`): `automod`، `automod_flag`. إشعارات: `automod_held`، `automod_released`.

### متغيرات البيئة (كلها اختيارية)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `AUTOMOD_ENABLED` | `1` | `0` يعطّل الفحص (تبقى الواجهات البرمجية) |
| `AUTOMOD_DELAY_MIN` | `10` | مدة التأخير الذكي بالدقائق |
| `AUTOMOD_ADAPTIVE_RL` | `1` | `0` يعطّل الحدود المتكيفة |
| `AUTOMOD_LLM` | معطّل | `1` يستخدم `ctx.llm.classify` (إن وُجدت) للحالات الحدّية ≥ 0.35 — تكلفة ضمن ميزانية LLM اليومية |
| `AUTOMOD_IMAGE_URL` | معطّل | مزوّد صور خارجي/ذاتي الاستضافة: يستقبل البايتات ويعيد JSON `{score}` أو `{nsfw}` أو فئات nsfwjs |
| `AUTOMOD_IMAGE_TOKEN` | — | يُرسل كـ Bearer للمزوّد أعلاه |

### الجداول (الترحيل 014، إضافي فقط)

`automod_items` (عنصر لكل هدف: الحالة، الحالة السابقة، الدرجة، الفئات، الأسباب، الإشارات، مصدر القرار، وقت الإفراج، من قرّر)، `automod_domains`، `automod_hashes`، `automod_nudges` (المستوى والنتيجة فقط، دون نص).

### الحدود المعروفة

- المصنّف معجمي: يفوته الإيذاء الضمني والسخرية، وقد يخطئ في الاقتباس («قال لي: يا غبي»). الأثر محدود لأن الحد الأقصى للآلة هو الحجز المؤقت.
- فحص البشرة إرشادي ومعروف بالإيجابيات الكاذبة (الوجوه القريبة، الرمل، الخشب) — لذا يقتصر على التمويه.
- في وضع الـ bus دون `gate()` قد يظهر المنشور لأجزاء من الثانية قبل حجزه، وقد تخرج إشعارات الإشارة/النشر؛ الخطاف الاختياري في `INTEGRATION.md` يزيل هذه النافذة.
- قائمة الشبيهات تعرف علامات محددة (Pi، بنوك سعودية، منصات كبرى)؛ تُوسَّع في `BRANDS`.
