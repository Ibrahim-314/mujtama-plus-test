# المسار الثاني: الهوية والملف الشخصي (v2.3)

## المرحلة 6: الملف الشخصي الغني
- صورة شخصية وغلاف حقيقيان مع **قص وتكبير وتدوير** داخل التطبيق (Canvas)، ثم رفع وتحويل إلى **WebP بثلاثة أحجام** (‏64/200/400 للصورة، 600/1200/1800 للغلاف) مع حذف بيانات EXIF والموقع.
- روابط (حتى ٥، تُرفض الروابط غير الآمنة مثل `javascript:`)، موقع، مجالات خبرة.
- حتى ٣ منشورات مثبتة، وأقسام قابلة للترتيب: أعمال، مقالات، مجتمعات.
- تخزين قابل للتبديل: القرص المحلي، أو أي تخزين متوافق مع S3 مثل **Cloudflare R2** (توقيع AWS SigV4 بدون مكتبات) مع `MEDIA_CDN_URL`.
- صفحة ملف جديدة بغلاف يتحرك مع التمرير، وبطاقة تعريف تظهر عند المرور على الاسم في الكمبيوتر.

## المرحلة 7: التوثيق والسمعة
- أربع شارات: شخص، منشئ، مؤسسة، خبير. طلب مع مستندات ومراجعة يدوية من لوحة «الثقة والنمو».
- السمعة تُحسب كل ٣٠ دقيقة: أفضل ٢٠ منشوراً فقط، و«مفيد» يساوي ٣ إعجابات، مع خصم للمخالفات.
- ١٠ شارات إنجاز تُمنح فوراً مع احتفال متحرك.
- كشف الانتحال: تطبيع الأسماء العربية (أ/إ/آ، ة/ه، ى/ي، التشكيل)، والأسماء المتشابهة بصرياً (`sa1ma` ≈ `salma`)، وبصمة الصورة الشخصية.
- شريط اكتمال الملف مع الخطوة التالية.

## المرحلة 8: الخصوصية الدقيقة
- حساب خاص بطلبات متابعة، وعند إلغائه تُقبل الطلبات المعلّقة.
- من يراسلك ومن يذكرك ومن يعلّق: الجميع، أو من تتابعهم، أو لا أحد.
- قائمة المقربين وجمهور «المقربون فقط» عند النشر.
- كلمات مكتومة تُخفي المنشورات من الخلاصة.
- رسائل غير المتابَعين تذهب إلى «طلبات الرسائل».
- كل القواعد في ملف واحد: `server/lib/policy.js`.
- معاينة «كيف يراك الآخرون».

## المرحلة 9: الحسابات المتعددة والمؤسسات
- إضافة حتى ٥ حسابات والتبديل بينها بلمسة، والجلسات محفوظة في ملف تعريف ارتباط HttpOnly.
- حسابات مؤسسات بأدوار: مالك، مدير، محرر. دعوات، تغيير أدوار، نقل ملكية.
- النشر باسم المؤسسة بدون مشاركة كلمة المرور، والأمان والخصوصية والإدارة تعمل دائماً باسم الشخص.
- سجل نشاط الفريق، ولوحة مؤسسة بالإحصائيات.

## المرحلة 10: التعريف والاحتفاظ
- جولة تفاعلية تبرز عناصر الواجهة، أو بطاقة مختصرة حسب تجربة A/B.
- اقتراحات متابعة ذكية: الاهتمامات، والدولة، ومن يتابعهم أصدقاؤك، والتوثيق، مع سبب لكل اقتراح.
- ٥ تحديات للأسبوع الأول مع شريط تقدم واحتفالات.
- رسالة ترحيب تلقائية من المجتمع عند الانضمام.
- قمع التسجيل: سجّل ← أكمل التعريف ← تابع ← نشر ← عاد في يوم لاحق، مع نسب التسرب.
- تجارب A/B بتوزيع ثابت لكل مستخدم ونتائج التحويل لكل نسخة.
- رسوم توضيحية أصلية لشاشات البداية.
