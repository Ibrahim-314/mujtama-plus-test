# مجتمع بلس — الإصدار 2.3.0

منصة اجتماعية (Social Platform Layer) تعمل داخل Pi Browser، مبنية من الصفر.
**التعقيد خلف الشاشة، البساطة أمامها.**

## طريقتا التشغيل
| الوضع | كيف | البيانات |
|---|---|---|
| تجريبي محلي | افتح `index.html` مباشرة | على الجهاز فقط |
| متصل (متعدد المستخدمين) | `cd server && npm start` ثم افتح `http://localhost:8080` | قاعدة بيانات مشتركة |

الواجهة تكتشف الخادم تلقائياً (`/api/health`). إذا وُجد: تسجيل دخول، ومزامنة كل العمليات، وتحديث فوري. وإذا لم يوجد تعمل كنسخة تجريبية.

## التشغيل السريع
```bash
# تطوير (SQLite مدمج، بدون أي اعتماديات)
cd server && npm start             # http://localhost:8080
npm test                           # 7 اختبارات تكامل (مستخدمان حقيقيان)

# إنتاج (PostgreSQL + ffmpeg)
cp .env.example .env && docker compose up -d --build
```
أول حساب يُسجَّل يصبح **مدير المنصة** (لوحة الإدارة).

## هيكل المشروع
```
index.html theme.css        الواجهة (RTL/LTR، Mobile-first)
store.js feed.js app.js      النواة: الكيانات، الخلاصة، الشاشات
v12.js                       طبقات 1.2: الفيديو، السلاسل، النقاشات، الأحداث، القوائم، الترجمة، السمعة، السلامة…
sync.js                      2.0: الربط بالخادم (مصادقة، مزامنة، SSE، رفع وسائط)
pi-adapter.js                تكامل Pi (معطّل حتى PI_ENABLED=1)
server/                      الخادم — انظر ARCHITECTURE.md
```

## الواجهة (v2.1)
`theme.css` نظام التصميم (ألوان، مسافات، ظلال، حركة، فاتح وداكن) · `ui.js` طبقة التجربة: أيقونات SVG، شريط تنقل عائم، شريط جانبي وعمود اقتراحات حي على الشاشات الكبيرة، إعجاب بلمسة، تفاعلات بضغطة مطوّلة، قلب عند النقر المزدوج، سحب للتحديث، إغلاق النوافذ بالسحب، عارض صور، اختصارات لوحة المفاتيح (`n` منشور، `/` بحث). انظر `DESIGN.md`.

## الأساس الهندسي (v2.2 · المسار الأول من خطة التطوير)
| الأمر | ماذا يفعل |
|---|---|
| `npm run build` | حزمة إنتاج مصغّرة بأسماء مُبصمة وضغط Brotli/Gzip في `dist/` |
| `npm run budget` | يفشل إذا تجاوز حجم الحزمة الميزانية (JS ‏90KB، CSS ‏14KB بعد الضغط) |
| `npm run lint` · `npm run typecheck` | ESLint وفحص أنواع TypeScript على كود الخادم |
| `npm test` | اختبارات الواجهة البرمجية والوحدات |
| `npm run test:e2e` | رحلات حقيقية في Chromium + فحص الوصول (axe) + مقارنة لقطات |
| `npm run test:load` | اختبار حمل (autocannon)، و`tools/k6-load.js` لـ 1,000 مستخدم |
| `npm run seed` | بيانات تجريبية عربية واقعية (`SEED_USERS`, `SEED_POSTS`) |
| `node server/scripts/migrate.js up\|down N\|status` | ترحيلات قاعدة البيانات |

التفاصيل في `docs/ENGINEERING.md`، ومكتبة المكونات في `/gallery.html`.
